# Polyvault – 3D asset marketplace (React + Three.js + GSAP + Node/Express + Supabase)
1. Supabase: SQL Editor > run server/supabase.sql. 
2. cd server && cp .env.example .env (fill keys) && npm i && npm start
3. cd client && npm i && npm run dev  -> http://localhost:5173
Demo logins (one-click chips on the login page): admin@demo.com/admin123, dev@demo.com/dev123, user@demo.com/user123, paid@demo.com/paid123
Download quality is enforced server-side: guest=low, logged-in=medium, paid/admin=high.
